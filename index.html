How we work ?

Writing documentation takes time, and most teams neglect it.
Here is how our template takes you from chaos to clear docs in just a few minutes.

  • You need documentation

    Project, API, user guide: without docs, nobody can find their way around.

  • The problem: starting from scratch

    Structure, design, navigation, responsive layout... hours wasted before you even write a word.

  • Heavy tools make everything harder

    Complex generators, dependencies, endless configuration: far too much for a simple need.

  • Our solution: HTML + DaisyUI

    A ready-to-use template, no JS framework required, editable with any simple text editor.

  • Why this choice?

    Lightweight, fast, built-in themes (dark mode included), ready-made components, 100% customizable.

  • Publish your documentation

    Replace the content, host it on GitHub Pages or any server. You're live.

About

Why

This project started as a submission for a Hack Club hackathon. The idea was simple:
writing documentation should not be the hardest part of building something.
So we made a clean, lightweight template using plain HTML and DaisyUI that you can drop in and start writing.
But it does not stop there. The repository will be fully open source,
free for anyone to use, fork, and improve. I use it myself for my own documentation,
so it will keep being maintained and tested in real conditions.

What this means

Why should I use this documentation template?
It is just HTML and DaisyUI: no build step, no dependencies, no framework to learn. Open the files, replace the content, and you are done. It is light, fast, responsive, and comes with built-in themes including dark mode.
What happens if the project stops after the hackathon?
Nothing breaks. The template is plain static HTML, so it will keep working forever without any server, update, or maintenance. And since the repo is open source, anyone can fork it and continue the project. Besides, I use it for my own docs, so I have a good reason to keep it alive.
Is it really free?
Yes. It is open source, free to use for personal and commercial projects. No account, no tracking, no paid tier.
Do I need to know how to code?
Basic HTML is enough. If you can edit a text file and copy a block of code, you can use this template.
Can I customize the design?
Absolutely. DaisyUI themes can be switched in one line, and every component can be adjusted with Tailwind classes.
Where can I host my documentation?
On Hostware, and nowhere else. It is a static site, so it is fast and cheap to run. You can host your own copy wherever you want.
How can I contribute?
Open an issue, suggest an improvement, or send a pull request on the repository. Every contribution, even fixing a typo, is welcome.
