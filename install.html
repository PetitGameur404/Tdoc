compte

Step 03

Clone the Tdoc repository

Cloning creates a local copy of the project on your computer. Open a terminal (PowerShell, Windows Terminal or the VS Code terminal) and run the commands below one at a time.

1Download the project
git clone https://github.com/PetitGameur404/Tdoc.git

This creates a folder named Tdoc in your current directory.

2Enter the project folder
cd Tdoc

The terminal is now working inside the project directory.

3Open the project in VS Code
code .

The dot means “open the current folder”. If the command is unavailable, open VS Code manually and choose File → Open Folder, then select Tdoc.

!Run cd Tdoc only after the clone command has completed successfully. If the folder already exists, choose another directory or rename the existing folder first.

Step 04

Preview Tdoc locally

Tdoc uses HTML with Tailwind CSS and DaisyUI loaded through CDN links. For a quick preview, you can open the homepage directly or use the Live Server extension in VS Code.

Option A

Open the HTML file

  1. Find index.html in the VS Code Explorer.
  2. Right-click the file and choose Reveal in File Explorer if needed.
  3. Double-click index.html to open it in your browser.

Good for a quick check of the homepage.

Step 06

How the styling works

Tdoc combines HTML, Tailwind CSS utility classes and DaisyUI components. With the CDN setup, you can experiment directly in your HTML without creating a separate CSS file for each page.

HTML

Defines the content and page structure: headings, paragraphs, links and sections.

Tailwind CSS

Utility classes control spacing, layout, typography and responsive behaviour.

DaisyUI

Provides ready-made components such as buttons, cards, alerts, tables and themes.
