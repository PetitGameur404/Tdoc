Installer et lancer Tdoc

Guide simple pour installer les outils nécessaires, cloner le projet depuis github et lancer la documentation.

étape 01

Les prérequis

éditeur de code léger pour modifier le projet et utiliser le terminal.

Télécharger VS Code ↗

Git

Outil pour cloner et suivre les versions du depôt officiel Tdoc

Installer Git ↗

étape 02

clonner et ouvrir le projet

ouvrirton terminal et exécute ces comende

# 1. cloner le dépôt GitHub

git clone https://github.com/PetitGameur404/Tdoc.git

# 2. Entrer dans le dossier du projet

cd Tdoc

# 3. Ouvrir dans VS Code

code .

ℹ️ Si la commande code .ne marche pas, ouvre VS Code et fais Fichier → Ouvrir un dossier.

  • 📁 /assets — Images, icônes et scripts
