Contributing to Tdoc

Why contribute ?

Tdoc is open source and welcomes contributions.
Whether it's a typo, a new theme or a new feature, every contribution helps.

Ways to contribute :

Type Description Difficulty
Report a bug Open an issue on GitHub Easy
Fix a typo Edit the docs directly Easy
Improve the docs Add examples, clarify steps Medium
Add a theme / component Extend the template Medium
Translate Add a new Language Medium

Step-by-step how to contribute ?

1) In a fisrt time you need to fork the repository

For fork the project is very easy go to Tdoc repository.
and click on the Fork button you can refere with the image above.

2) Clone, branch and push

Please Keep the same code style (Tailwind + DaisyUI classe only) if you dont use the same style your contribution or reject. reference of the daisyUI components.
Test your code in light and dark themes and finaly write commits in English.
Be kind and respectful

If you are unsure how to make changes without affecting other aspects of the appearance,
you can refer to the design page.

Thanks you very much for your contribution and help Tdoc to grow in popularity
